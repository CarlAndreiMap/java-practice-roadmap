## Goal

Analyze a range of numbers entered by the user and identify which ones are prime, perfect squares, or have ascending digits, then summarize the results. This reinforces combining loops, conditionals, and math logic in a less templated way than basic exercises.

## Requirements

- [ ] Ask the user for a start and end number defining a range
- [ ] Validate the input: if start > end, re-prompt instead of crashing or producing wrong output
- [ ] For each number in the range, determine if it is prime
- [ ] For each number in the range, determine if it is a perfect square
- [ ] For each number in the range, determine if its digits are in strictly ascending order
- [ ] Print each number that matches at least one category, along with which categories it matched
- [ ] Print a summary at the end: total numbers checked, count of primes, count of perfect squares, count of ascending-digit numbers

## Concepts & Skills Targeted

- Nested loops (inner loop for primality checking)
- Loop control statements (`break` / `continue`) used meaningfully
- Complex boolean logic and multi-condition checks
- Digit manipulation using `%` and `/` without arrays
- Input validation using a re-prompt loop
