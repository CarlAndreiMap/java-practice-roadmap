**Phase:** 2 - Combining Basics

**Status:** 🟡 In Progress

**Date Started:** 2026-09-07

**Date Completed:** 

## Goal

Track a list of students and their scores using arrays, compute summary statistics (average, highest, lowest, pass/fail counts), and print a sorted, formatted report table. This introduces arrays and parallel-array management as the first step beyond tracking single running values.

## Requirements

- [ ] Ask the user how many students there are, and size the arrays accordingly
- [ ] Store each student's name and score in parallel arrays
- [ ] Validate each score is between 0–100, re-prompting only for that student if invalid
- [ ] Compute the average score across all students
- [ ] Determine the highest score and which student(s) achieved it
- [ ] Determine the lowest score and which student(s) achieved it
- [ ] Count how many students passed vs. failed (using a threshold you define)
- [ ] Sort students by score in descending order using your own sorting logic (not `Arrays.sort()`), keeping both arrays in sync
- [ ] Print a formatted table of all students (sorted) and their scores
- [ ] Print the summary statistics after the table

## Concepts & Skills Targeted

- Declaring, filling, and iterating over arrays
- Parallel arrays (keeping two arrays in sync by index)
- Array bounds and off-by-one awareness
- Writing a basic sorting algorithm manually (selection sort or bubble sort)
- `printf` / `String.format` width specifiers for aligned table output
- Method extraction for readability
